## Application Description
This project implements a University Student Registration and Academic System built completely in Oracle PL/SQL. It manages students, course offerings, and semester enrollments, incorporating advanced PL/SQL programming constructs such as user-defined records, collections, explicit cursors, bulk data processing, stored procedures/functions, and robust exception handling.

## How to Run Instructions
1. Execute '00_schema/01_create_tables.sql' in Oracle Database schema to build tables and constraints.
2. Run '00_schema/02_insert_sample_data.sql' to populate sample student and course rows.
3. Compile the stored procedure script in '01_procedures/register_student_batch.sql'.
4. Compile the stored function script in '02_functions/calculate_gpa.sql'.
5. Execute the test scripts located under '03_tests/' to verify success and error handling scenarios.
